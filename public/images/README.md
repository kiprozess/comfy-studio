# Comfy logo

`comfy-logo.svg` is the unmodified logo from https://comfy.org/icons/logo.svg,
linked by the official brand portal at https://comfy.org/brand/.
Retrieved on 2026-10-16. The logo's original colors and aspect ratio are retained.

## Example model

`default-model.png` is the AI-generated fictional person supplied by the project author on 2026-10-18 for use as the default Try-on photo. It is included with the author's permission as a sample image. Visitors can replace it with their own photo; no generation starts automatically.

## Demo outfit lookbook

`demo-outfits.png` is the 16-outfit lookbook created and supplied by the project author on 2026-10-18 and explicitly approved for use as demo references. The original image is included unchanged. It has four columns and four rows: the first eight outfits are shown in the Male collection and the last eight in Female.

The sidebar previews one cell at a time. When an outfit is selected, the server crops that cell and sends only that outfit as the clothing reference. The retired lookbook is not used.
