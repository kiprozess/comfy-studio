# Outfit preview atlas

`outfit-presets.png` was generated with ImageGen on 2026-10-16 for this project's
styling sidebar. It contains original illustrative preset previews, not product
listings or images copied from the reference screenshots.

The atlas has four equal columns and four equal rows. The first two rows contain
eight male styling presets; the last two contain eight female styling presets.
The sidebar displays individual cells through CSS background positioning.

These thumbnails are demo references. They do not imply a connected try-on model.
